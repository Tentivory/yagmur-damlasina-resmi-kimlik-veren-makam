# Yağmur Damlasına Resmi Kimlik Veren Makam

> **UYARI:** Bu yazılım, atmosferik su kütlelerinin kimliksiz dolaşmasını önlemek üzere kurulmuş bağımsız bir makamdır. Şaka değildir. Şaka gibi durması, şakanın resmiyetidir.

## Vazife

Her yağmur damlasının:
- bir unvanı,
- bir sicil numarası,
- bir memleketi,
- ve bir “niçin düştüğü” gerekçesi

olmalıdır. Aksi halde damla, hukuken buhardır.

## Kurulum

```bash
python3 damla_kimlik.py
```

Bağımlılık yoktur. Python 3 yeter. İnternet de gerekmez; damlalar zaten yukarıdadır.

## Örnek Çıktı

Program her çalıştırmada rastgele bir damlaya berat düzenler. Örnek:

```
BERAT-I HUMAYUN
Sicil: YDMR-48291
Unvan: Evvelki Cuma’nın Pervasız Damlası
Memleket: Karadeniz üzeri, tahmini
Gerekçe: Balkona düşmek için resmi izin aldı.
```

## Katkı

Pull request atmadan önce kendi damlanıza kimlik çıkartın. Kimliksiz PR kabul edilmez.
